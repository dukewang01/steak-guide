# 牛排熟度指南 · 手绘版（Steak Doneness Guide）

手绘风格的单文件离线指南，覆盖 8 档熟度、触感测试、中英熟度对照误区、酱汁与配酒、部位选择与食品安全底线。

- `index.html` —— 入口页（三个入口）
- `steak.html` —— 完整手绘版指南（**中英双语**，14 节，单文件离线、无 CDN；右上角「EN / 中文」整篇切换语言）
- `game/index.html` —— 🥩 **《我要吃牛排》60 秒小游戏**（单文件零依赖，手机可直接玩）
  - 三个身份：**厨师**（火候窗：核心温度带宽 × 焦壳合格线）、**服务员**（耐心 × 营业额：两秒半内确认熟度）、**客人**（趁热吃：拍照 = 牛排降温）
  - 每条机制都从指南里的真规则长出来：触发你的都是它；60 秒一局，结算有称号、可存成绩卡（带二维码）
  - 玩：<https://dukewang01.github.io/steak-guide/game/>
- `card.png` —— 一页速查卡（A4 可打印）
- `full.png` —— 全篇长图·中文（手机阅读）
- `full_en.png` —— 全篇长图·English（same layout, English edition）

内容依据原始资料整理，数据未作改写；指南用于培训与内部参考，食品安全底线以当地法规为准。
